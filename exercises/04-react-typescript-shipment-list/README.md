# Exercise 04: React + TypeScript Shipment List

## Prompt

Build a `ShipmentList` component that fetches shipments and renders them.

## Requirements

- Fetch from `/api/shipments`.
- Type the API response.
- Show loading, error, empty, and success states.
- Render origin, destination, and status.
- Add a controlled status filter.
- Use stable list keys.

## What To Explain Out Loud

- Difference between props and state.
- Why `useEffect` is used for fetching.
- What causes a re-render.
- Why TypeScript union types help with shipment statuses.
